Find-a-Line data server

This server holds copies of elevation data for Find-a-Line, a program that finds possible highlines in elevation data. Find-a-Line installations download the tiles of regions whose data cannot be read from their owner on demand. It serves files only; there is nothing to sign in to, and the limits per address keep it usable for everyone.

    Privacy

    An installation that downloads from the project's data server shows it its address and which tiles it asks for. The server writes down the time, the address, the dataset (not the tile), the size, whether the request was served or refused, how long it took, and the Find-a-Line version of each request. It keeps this for at most 14 days, to hold the service within its limits, and uses it for nothing else. To never contact the data server, set FINDALINE_MIRROR_URL to off; the regions it serves then use coarser data.
